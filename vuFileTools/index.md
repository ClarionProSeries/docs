# vuFileTools

Version: 5.0

Last Updated: 2026-11-19 (Build: 212)

Copyright (c) 2026 Clarion ProSeries by LANSRAD. All rights reserved.

![vuFileTools logo](assets/images/vuFileTools270x90.png)

[Visit the vuFileTools product page](https://clarionproseries.com/products/vufiletools)

**vuFileTools brings more than 200 ready-to-use Windows utility functions to Clarion applications.** Instead of writing lengthy Windows API code, you can use established functions for everyday programming tasks and advanced Windows features.

The library covers file and directory management, disk information, Windows and system operations, running programs and monitoring processes, network information, registry access, shortcuts, string manipulation, data conversion, interprocess communication, and other utilities. Browse the [complete A–Z function reference](functions/index.md) or [functions by category](categories/index.md).

## Window Dimming — an additional feature

Build 212 includes optional [Window Dimming](window-dimming/index.md), which makes a parent window less prominent while an update form or message window is displayed. It supports ABC and Legacy applications, configurable overlay colors, standard Clarion messages, and manual controls.

**Window Dimming is disabled by default in vuFileTools.** When you want it, open **vuFileTools Initialization** under Global Extensions, select the **Window Dimming** tab, uncheck **Disable window dimming templates**, and compile. The normal automatic options are already selected. A Windows 8-or-later compatibility manifest is required for Window Dimming, not for the rest of the library.

Developers who need only Window Dimming can also obtain the standalone [cdWindowDim Code Drop](https://clarionproseries.com/products/cdwindowdim).
