# cdWindowDim - Task Guides

- [Custom Message Windows](custom-message-windows.md): add a local extension to a custom or third-party message-window procedure.
- [Automatic Message Dimming](automatic-messages.md): dim behind supported MESSAGE, STOP, and HALT dialogs without changing calls.
- [Automatic Window Dimming for Browses](automatic-browse.md): let supported browse/update procedures dim their parent windows.
- [Manual Dim and Restore](manual-dimming.md): place the dimming operation around a normal procedure or report call.
- [Dimming a Window Started with START](started-children.md): start a child on a separate thread and restore its parent when the child actually closes.
- [Runtime Dimming Controls](runtime-controls.md): add Enable, Disable, Toggle, and Get Dimming Status commands, including saving a user preference.
- [Window Appearance](window-appearance.md): choose global or per-procedure colors and strength.
- [Temporarily Disable Dimming](temporarily-disable.md): turn off one operation or the whole template without removing settings.
- [Multi-DLL Applications](multi-dll.md): add the global extension only to APPs containing the affected windows.
- [Hand-Coded Integration](../hand-coded-integration.md): call the DLL functions directly.
- [DLL Function Reference](../functions/index.md): view the function prototypes and Clarion examples.
