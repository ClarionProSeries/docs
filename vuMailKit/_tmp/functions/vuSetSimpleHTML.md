# vuSetSimpleHTML()

## Clarion prototype

**Prototype:** vuSetSimpleHTML(LONG InState), SIGNED, PROC, PASCAL, RAW, NAME('vuSetSimpleHTML')

Turns Simple HTML mode on or off for later send calls.

When Simple HTML mode is on, vuMailKit builds a modest HTML wrapper, optionally inserts a header image and footer image, and places the current body content in the message area.


This is the quick path for a well-dressed HTML email. You do not need to create the outer HTML document yourself.

## Parameters

| Name | Description |
|---|---|
| InState | 0 turns Simple HTML off. Any non-zero value turns it on. |

## Example (Clarion)
```clarion
rc      LONG
cFrom   CSTRING(256)
cTo     CSTRING(256)
cCC     CSTRING(256)
cBCC    CSTRING(256)
cSubj   CSTRING(256)
cBody   CSTRING(2048)
cBodyText CSTRING(2048)
cAttach CSTRING(260)

rc = vuResetSimpleHTML()
rc = vuSetSimpleHTML(1)
rc = vuSetSimpleHTMLNormalizeBody(1)

cFrom = ''
cTo = 'customer@example.com'
cCC = ''
cBCC = ''
cSubj = 'Simple HTML message'
! This sample hard-codes the text so the example is self-contained.
! In a real program this is usually text from a TEXT control, TPS memo,
! customer note, template merge, or generated report text.
cBodyText = 'Thank you for your order.<13,10><13,10>' & |
            'We appreciate your business.'
cBody = CLIP(cBodyText)
cAttach = ''

rc = vuSendMailWait(cFrom, cTo, cCC, cBCC, cSubj, cBody, cAttach)

vuResetSimpleHTML()
```

## Notes

- The setting is sticky until you change it or call [vuResetSimpleHTML](vuResetSimpleHTML.md).
- This setting is runtime-only and is not persisted between application runs.
- Simple HTML mode expects cBody to contain the message body only. Do not pass a full HTML document with &lt;html&gt;, &lt;head&gt;, or &lt;body&gt; tags when this mode is enabled.
- For the easiest path, call [vuSetSimpleHTMLNormalizeBody](vuSetSimpleHTMLNormalizeBody.md) with 1 and pass ordinary text. Normal line breaks are converted for HTML display. The &lt;13,10&gt; values in the sample are only for a self-contained Clarion source string; text from a TEXT control, TPS memo, customer note, generated report, or similar field can be passed as-is.
- The generated wrapper includes a UTF-8 charset meta tag and uses the normal vuMailKit HTML send path so the plain-text alternative is still generated by the existing MIME build flow.
- For an end-to-end example with optional header and footer images, see [Send a Simple HTML Email with a Company Logo](../getting-started/send-a-simple-html-email-with-a-company-logo.md).
- For images inside an ordinary normalized body, use the embed-attachments marker and pass local image files or remote http/https image URLs in the Attach parameter. See [Send an embedded image](../getting-started/send-an-embedded-image.md).
