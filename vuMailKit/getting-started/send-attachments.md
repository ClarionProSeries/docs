# Send Attachments

vuMailKit can send attachments along with outgoing email.

Attachments do not have to be images. They can be ordinary files such as PDFs, documents, spreadsheets, or other content you want to include.

If you want the image to appear inside the HTML body instead of as a normal attachment, see:

- [Send an embedded image](send-an-embedded-image.md)
