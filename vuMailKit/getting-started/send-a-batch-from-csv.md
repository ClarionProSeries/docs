# Send a Batch of Emails from CSV

vuMailKit supports CSV-based email sending for developers who want to prepare a set of outgoing messages and send them as a group.

This is useful when you already have message data in rows and want a simple bulk-send workflow.

If you are just getting started, focus on sending one email first. Then move to CSV sending after the basic send path is working.
