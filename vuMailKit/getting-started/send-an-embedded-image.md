# Send an Embedded Image

An embedded image appears inside the HTML email body instead of showing up only as a normal attachment.

This is useful for:

- logos
- banners
- product images
- branded email content

Keep the HTML simple at first and verify that the image path or image reference is correct for your chosen workflow.
