# Support

Contact Clarion ProSeries using the online contact form:

<a href="https://www.clarionproseries.com/contact" target="_blank" rel="noopener">
https://www.clarionproseries.com/contact
</a>

If the link does not open in your web browser from a compiled CHM help file, copy the address above and paste it into your browser. The contact form should be used in a modern browser, not inside the Windows Help viewer.

Include the xSearch version/build, Clarion version, whether the application is single EXE or multi-DLL, the primary browse file, selected tag storage method, and any compiler diagnostics. For a multi-DLL problem, identify the Data DLL APP and the importing APP.

For compiler failures, a short extract from the generated source is more useful than a long list of errors after one missing declaration.
