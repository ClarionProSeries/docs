# xSearch - Template Registration

The xSearch installer can register the template as part of installation. If you choose to register it manually, follow the normal Clarion template-registration process:

1. In Clarion, select **Tools > Edit Template Registry**.
2. In the **Template Registry** window, choose **Register**.
3. Browse to the template folder for the selected Clarion version, such as C:\\Clarion12\\accessory\\template\\win.
4. Select xsearch.tpl and click **Open**.
5. Confirm that xSearch appears in the registered templates.

If you replace an existing registered copy of the template, close and reopen the APP so Clarion can recognize the changed template source. Re-registering the same file is normally unnecessary.

Next, read [Using the Template in Your Application](template-usage.md).
