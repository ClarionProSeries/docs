# xSearch

![Clarion xSearch - Clarion ProSeries Templates](assets/images/xSearch270x90.gif)

Current Version: xSearch 5.0

Build: 248

Release Date: 11-10-2026

Last Updated: 11-10-2026

Copyright (c) Clarion ProSeries by LANSRAD. All rights reserved.

**Find the records you need. Keep the records you find.**

xSearch gives Clarion ABC applications multi-field searching and record tagging directly in their browses. Users can search beyond a browse's current locator, mark matching records, review the results, and work with that selection later in the same application.

Unlike an ordinary browse filter, xSearch creates a **tagged selection** that can be retained and reused. Searches, filters, reports, processing, and exports can work with the records the user has selected.

## What xSearch can do

- Search fields in a primary file and optionally related files.
- Tag matched records and show a checkmark beside an existing browse column.
- Optionally highlight the entire tagged row in a color you choose, while keeping the normal selection highlight.
- Tag or untag a single record, tag all, clear all tags, or browse only tagged records.
- Keep tags for one browse, for the application session, or across program restarts.
- Search using displayed lookup text, not just stored codes.
- Maintain search history and named tag sets.
- Use SQL pre-filtering where appropriate.
- Print standard Clarion or supported Fomin Report Builder reports, or run processes, using the tagged selection, with an optional tagged-record question and count.
- Export records to CSV, UTF-8 CSV, TSV, XML, JSON, HTML, or Excel XLSX.
- Choose English, Spanish, or add your own translation source.
- Use the built-in Classic export dialogs without importing any procedures, or optionally import Classic or Modern editable windows. Each complete TXA set contains seven procedures.
