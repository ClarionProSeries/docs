# xSearch - Requirements

xSearch supports these versions of Clarion:

- **Clarion 12**
- **Clarion 11.x**
- **Clarion 10**
- **Clarion 9.x**
- **Clarion 8**
- **Clarion 7**
- **Clarion 6**
- **Clarion 5.5**

xSearch uses the following template chain:

- **ABC Template Chain**

xSearch is designed for **AppGen applications using ABC Browse procedures**.

xSearch works with both **single-EXE** and **multi-DLL** applications.

Active technical support covers **Clarion 9.1 through Clarion 12**. The release was verified using **Clarion 9.1 Win32**.

xSearch is compiled into the application. No separate xSearch runtime DLL is required.
