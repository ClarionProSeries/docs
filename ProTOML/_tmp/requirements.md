# ProTOML - Requirements

ProTOML is designed for Clarion Win32 applications.

The current verified ProTOML environment is Clarion 9.1 Win32.

ProTOML supports:

- ABC applications
- Legacy applications
- AppGen applications using the ProTOML global template
- Hand-coded applications
- Single-EXE applications
- Multi-DLL applications with the ProTOML template added to the EXE app

The target computer requires a compatible Microsoft .NET Framework 4.x runtime. The current ProTOML runtime targets .NET Framework 4.7.2.
