# ProTOML - Demo and Licensing

The ProTOML demo lets developers evaluate ProTOML with the supplied demonstration applications and examples.

Demo mode is provided for product evaluation. A valid ProTOML developer license is required for licensed product use.

A licensed copy of ProTOML uses the developer license value supplied with your purchase. Enter that value exactly as supplied in the developer-license field. For demo use, the template defaults to `PTM-DEMO`.

The normal template integration initializes the process once through `Toml.InitializeLicense(...)`. Hand-coded applications can do the same explicitly.
