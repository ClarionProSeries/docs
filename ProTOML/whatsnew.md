# What's New in ProTOML

The first ProTOML release brings a high-level TOML wrapper and global template to Clarion developers.

## Highlights

- Create, load, edit, and save TOML documents
- Store and retrieve individual Clarion values
- Write and read an ordinary GROUP with one call; BINDABLE is not required
- Write and read the current FILE record buffer with one call; BINDABLE is not required
- Write and read an ordinary QUEUE as a TOML array of tables; BINDABLE is not required
- Store a complete document in a string, MEMO, BLOB, or .toml file
- Combine several kinds of Clarion data in one document
- Exchange TOML data with modern languages and tools
- Use the supplied customer demo to see the complete workflow
