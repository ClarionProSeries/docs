# Getting Started

ProTOML includes a high-level Clarion wrapper and a broader low-level API. Most real-world applications begin with only a small set of high-level methods.

## The common workflow

For a normal Clarion application:

1. Install ProTOML.
2. Register the template if the installer did not register it automatically.
3. Add the ProTOML global template to the EXE application.
4. Enter the developer license in the template.
5. Write the high-level calls your application needs.
6. Compile and run the application.
